# 🚀 Antigravity iOS Client

> Полноценный нативный клиент **Google Antigravity** для iOS, написанный на **SwiftUI 6** (Swift 6 Concurrency), с авторизацией через **Google**, поддержкой артефактов, слэш-команд, роя субагентов, превью dev-серверов и автоматической сборкой/подписью в GitHub Actions с доставкой в Telegram.

---

## ✨ Возможности

* 🤖 **Автономный агент (Gemini 2.5 Pro / Flash):** Полноценное управление облачным рантаймом, выполнение shell-команд, редактирование файлов.
* 🔑 **Google Авторизация:** Бесшовный вход через Google Account, статус квот Vertex AI / Gemini API.
* ⚡ **Слэш-команды:** `/goal`, `/plan`, `/schedule`, `/boost`, `/browser`, `/compact`, `/learn`, `/grill-me`, `/teamwork-preview`.
* 🛡️ **Human-in-the-Loop Approvals:** Карточки подтверждения опасных bash-команд и деплоев (`[Разрешить]`, `[Отклонить]`).
* 📜 **Система артефактов:** Просмотр архитектурных планов, Mermaid диаграмм, отчетов и виджетов генеративного UI.
* 🐝 **Рой субагентов:** Мониторинг параллельно работающих субагентов (исследователь кодовой базы, генератор 3D-иконок, CI/CD).
* 🌐 **Live Web Preview:** Встроенный браузер (WKWebView) для мгновенного тестирования запущенного веб-приложения на портах `:3000`, `:5173`, `:8080`.
* 🔍 **Код-дифы и Git:** Нативный просмотр добавленных и удаленных строк с подсветкой и кнопкой *Commit & Push*.
* 🎨 **3D-иконка и Apple Design:** Объемная иконка в стиле WWDC (темный обсидиан с неоновым кольцом в невесомости), fluid springs, стекломорфизм и темная тема.

## 🛠️ Архитектура сборки и подписи (CI/CD)

Пайплайн сборки полностью адаптирован из `aura-player`:

1. **XcodeGen:** Проект компилируется из декларативного файла [`project.yml`](file:///project.yml) без хранения тяжелых бинарных файлов Xcode в репозитории.
2. **Автоматическая подпись:**
   * Если в репозитории настроены секреты сертификата Apple (`APPLE_CERT_P12_BASE64`, `P12_PASSWORD`, `PROVISION_PROFILE_BASE64`), GitHub Actions автоматически подписывает `.ipa` вашим профилем разработчика.
   * Если секретов нет, создается чистый неподписанный `Antigravity-unsigned.ipa` для ручной подписи на телефоне через **Feather** / **ESign** / **SideStore**.
3. **Telegram Бот:**
   * После каждой сборки скрипт `.github/scripts/send_ipa_telegram.py` отправляет собранный файл `.ipa` прямо в Telegram чат `8559869613`.
   * Также генерируется OTA-страница для установки через Safari в 1 клик.

## 🔐 Секреты для настройки на GitHub (Settings ➔ Secrets and variables ➔ Actions)

| Секрет | Описание |
| :--- | :--- |
| `APPLE_CERT_P12_BASE64` | Сертификат разработчика `.p12` в формате Base64 |
| `P12_PASSWORD` | Пароль от файла `.p12` |
| `PROVISION_PROFILE_BASE64` | Мобильный профиль `.mobileprovision` в формате Base64 |
| `TELEGRAM_BOT_TOKEN` | Токен бота Telegram для отправки сборки |
| `TELEGRAM_CHAT_ID` | ID чата для получения файла (по умолчанию: `8559869613`) |
| `GITHUB_TOKEN` | Системный токен для публикации на GitHub Pages |
